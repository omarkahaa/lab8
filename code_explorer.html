📋 Project Overview

lab8-pygame is a pygame application that displays 100 animated squares moving around a window with realistic physics behaviors.

Key Features

🎯 Size-Based Speed Control: Larger squares move slower than smaller ones, creating varied animation
🔀 Direction Jitter: Random direction changes make movement less rigid and more natural
🏃 Flee Behavior: Smaller squares detect and move away from larger nearby squares
⏳ Limited Lifespan: Squares have random lifespans (30-180 seconds) and respawn when they expire
🎨 Visual Feedback: Real-time FPS counter and colorful squares on white background

🧮 Key Algorithms

Speed Limiting

speed = √(dx² + dy²)
if speed > max_speed:
  scale = max_speed / speed
  dx *= scale
  dy *= scale

Distance Calculation

distance = √(Δx² + Δy²)
Uses math.hypot() for precision

Flee Force Application

direction = (Δx, Δy) / distance
force = direction × FLEE_FORCE
dx += force_x
dy += force_y

⚡ Performance Characteristics

Complexity Analysis

  • Per Frame: O(n²) for flee checks
  • Per Square: O(n) flee distance checks
  • Target FPS: 60 (1000/60 ≈ 16.7ms per frame)

Optimization Notes

  • Vectorized operations (no trigonometry in hot path)
  • Early exits in flee logic
  • Direct arithmetic over function calls where possible
